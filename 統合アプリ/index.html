ログイン

はじめてのときは、システム管理者から配られたIDと仮パスワードでログインし、自分の職員番号（6桁）とパスワードを登録します。2回目からは職員番号でログインします。パスワードを忘れたときは、システム管理者に再発行を頼んでください。

スタッフ向け

はじめてのログイン・パスワード
  1. はじめては、システム管理者から配られた 仮のID と 仮パスワード でログインします。
  2. 「パスワード・職員番号の変更」の画面になるので、自分の職員番号（6桁の数字）と、英字と数字を含む8文字以上の自分だけが知っているパスワードを入れます。
  3. 2回目からは、職員番号とそのパスワードでログインします。職員番号を入れ間違えたときは、メニューの「パスワード・職員番号の変更」で直せます。
  4. ボタンを押したあと「○○しています…」と出ている間は処理中です。終わると自動で消えるので、ボタンを押し直さずに待ってください。
  5. パスワードを忘れたときは、システム管理者に「パスワード再発行」を頼んでください。
  6. 共用のパソコンでは、使い終わったら右上の「ログアウト」を押してください。
メニューとお知らせ
  • ログインするとメニューが出ます。上に「お知らせ」が出ているときは、交代を頼まれた・申請が承認された・却下された、などの知らせです。押すとその画面が開きます。
  • メニューに「承認待ち ○件」「⚠ 人数超過」などの赤い印が出たら、その画面を確認してください。
希望休の申請
  1. メニューの「希望休の申請」を開きます。受付中の期間だけ申請できます（受付の期間は画面の上に出ます）。
  2. カレンダーの日付を押し、種類（有・夏・特・×など）を選んで申請します。平日の「残り」は、その日にあと何人休めるかです（1日5人まで）。土日祝は「×」だけです。
  3. 受付中は5人を超えても申請できますが、超えた日に申請している人には注意が出ます。同じ日の人どうしで相談して、取り消すか別の日に移してください。
  4. 受付が終わると「調整中」になります。調整中は、5人を超えた日に申請していた人だけが、取り消し・5人未満の日への移動をできます。
  5. 申請を取り消すときは、その日付を押して「取り消す」を押します。下の「自分の申請」で一覧を確認できます。
  6. 日直・夜勤・振休が先に決まっている場合は、その日は申請できません（灰色の表示）。振休は、移したい平日を押して「振休をこの日へ移動」を選ぶと、別の日へ移す申請ができます。
勤務表を見る
  • メニューの「勤務表を見る」で、確定して配布された勤務表を見られます。「自分の勤務」はカレンダー、「全員」は一覧表です。
  • 確定後の勤務変更で変わったマスには、オレンジの枠（自分の勤務では「変更あり」）が付きます。
  • 時間休は「有12-17」（12時から17時まで休み）のように表示されます。
  • 「自分の勤務」の下の「あなたの振休」に、振休の対象になる出勤（土日祝の日直・業務・夜勤入り・夜勤明けと前回からの繰越）ごとに、振休の日か「次回へ繰越」かが出ます。「全員」の下には、全員の「次回へ繰越の振休」が出ます。
勤務変更・追加の申請（交代・受け渡し・募集・振休の交換・自分の勤務の変更・時間休）

メニューの「勤務変更・追加の申請」で、確定した勤務表を変える申請をします。下の小さな勤務表のマスを押しても選べます。選んだら「内容を確認」→ 変わるマスがオレンジで表示されるので、確かめて「申請する」を押します。

  • 交代：自分の日直・夜勤・残り当番と、相手の日直・夜勤・残り当番を同時に入れ替えます。「自分が渡す勤務」「相手」「代わりに引き受ける相手の勤務」を選びます。夜勤（入）は翌日の「明」も一緒に移ります。相手 → 承認者の順に承認されると反映されます。
  • 受け渡し：交換ではなく、日直・夜勤・残り当番を一方へ渡します。「どちら」で「やってもらう」（自分の勤務を相手に渡す）か「引き受ける」（相手の勤務を自分がする）を選び、「相手」と勤務の日を選びます。渡した人のその日は空き（平日は勤務、土日祝は休み）になります。夜勤（入）は翌日の「明」も一緒に移ります。相手 → 承認者の順に承認されると反映されます。
  • 募集（だれでも）：相手を決めずに、「だれでもいいので交代・引き受けしてほしい」ときに使います。
    • 「代わってほしい自分の勤務」と「募集の内容」（交代でも引き受けでもよい／引き受けてほしい／交代してほしい）を選び、必要なら「ひとこと」（全員に見えます）を書いて「募集する」を押します。その日が空いている人にお知らせが届きます。
    • ほかの人の募集は、「勤務変更・追加の申請」の一番上の「募集中の勤務（だれでも）」に出ます（メニューにも「募集 ○件」と出ます）。「引き受ける（交換なし）」か、交代に出す自分の勤務を選んで「この勤務と交代を申し出る」を押し、内容を確かめて「申し出る」を押します。先に申し出た1人が対象になります。
    • 引き受けの申し出は、そのまま承認者の承認へ進みます。交代の申し出は、募集した人が「自分の申請」で「申し出を受ける」か「断る（募集に戻す）」を選びます（メニューに「確認待ち ○件」と出ます）。受けると承認者の承認へ進みます。
    • 申し出た人は、承認者の承認の前なら「自分あての承認」の「申し出を取り消す」で取り消せます（募集中に戻ります）。募集をやめるときは「自分の申請」の「取り下げる」を押します。
  • 交代・受け渡しで土日祝の日直・夜勤が移ると、その振休も受け取った人のものになります。渡した人がその分の振休をもう取っている（日が決まっている）ときは、「内容を確認」のあとに「振休の扱い」が出るので、「同じ日の振休も相手に渡す」か「振休は取りやめ、相手の振休は次回へ繰越」を選びます。
  • 振休の交換：自分の振休と相手の振休の日を入れ替えます。片方に「繰越」（次回へ繰越の、日が決まっていない振休）を選ぶと、繰越の人が相手の振休の日に振休を取り、日が決まっていた人の振休が次回へ繰越になります。相手 → 承認者の承認が必要です。
  • 自分の勤務の変更：有・夏・特を取る／取り消す、出張・業務・研修などに変えます。振休はここでは変えられません（振休は「振休の交換」だけで動かします）。承認者の承認が必要です。
  • 前回からの繰越の振休は、今回の期間内に必ず取ります。また次回へ繰り越しになる申請（振休の交換・交代・受け渡し・承認後の取り消しを含む）はできません。
  • 時間休：遅く来る・早く帰る・途中で抜けるときの、時間単位の有給です。
    • 日付・種類を選び、「休む時刻（から）」「休む時刻（まで）」を選びます。休憩が日によって違う場合は「その日の休憩」も選びます。
    • 時間は休憩を除いて1時間単位で数え、1時間に満たない分は切り上げます。選ぶと「○時間」と表示されます。
    • 1年度（4月から）の上限は40時間（5日×8時間）で、申請中の分も含めて数えます。今の使用時間は画面に出ます。
    • 時刻を変える・取り消すときも「時間休」で、その日を選んで行います。
  • 休みが5人を超える・連続勤務が7日以上になる、などの条件から外れる場合は、理由（5文字以上）が必要です。理由はシステム管理者と承認者だけが見られます（交代の相手には見えません）。
  • 承認される前なら、「自分の申請」の「取り下げる」で取り下げられます。
  • 承認されたあとに取り消したいときは、「自分の申請」の「承認後の取り消しを申請」を押します。元の申請と同じく、相手（交代・受け渡し・振休の交換のとき）と承認者の承認で、勤務表が元に戻ります。承認後に同じマスがさらに変わっているときは、取り消せません。
自分あての承認
  • ほかの人から交代・受け渡し・振休の交換を頼まれると、お知らせが届き、メニューの「自分あての承認」に件数が出ます。
  • 内容と「勤務表で確認 ▼」で変わるマスを確かめ、「承認する」か「却下する」を押します。承認すると、承認者の承認に進みます。
  • 募集に申し出たものも、ここに「募集への申し出」として出ます。承認者の承認の前なら「申し出を取り消す」で取り消せます。
自分の集計
  • メニューの「自分の集計」で、日直・夜勤・残り当番・有給・時間休・振休などの回数を、年度や勤務表の期間ごとに見られます。
  • 見えるのは自分の分だけです。時間休は、年度の上限までの残り時間も出ます。
  • 確定したときから変わった自分のマスの一覧も見られます。

承認者向け

勤務変更を承認する
  1. 承認待ちの申請があると、お知らせが届き、メニューの「管理者の承認」に件数が出ます。
  2. 「承認待ち」の一覧で、内容・変わるマス（「勤務表で確認 ▼」）・条件から外れる点と理由を確かめます。
  3. 「承認する」を押すと、すぐに勤務表の実績に反映されます。「却下する」では理由を書けます（申請者に表示されます）。
  4. 自分が申請者または相手になっている申請は承認できません。ほかの承認者かシステム管理者が承認します。
  5. 「募集への申し出」の印があるものは、スタッフの募集にだれかが申し出た交代・受け渡しです（交代は、募集した人が申し出を受けたあとに承認待ちになります）。ふつうの申請と同じように確かめて承認します。
  6. 申請したあとに勤務表が変わっていると承認できません。その場合は却下して、申請し直してもらってください。
  7. 「すべて」に切り替えると、承認済み・却下・取り下げを含む全部の申請を見られます。
実績の集計・分析
  • メニューの「実績の集計・分析」で、範囲（年度・勤務表の期間・すべて）を選びます。
  • 全体（月別・年度）：当番・休み・時間休の回数、平日の休みの平均・最大、5人を超えた日、勤務変更の件数を、月別の表とグラフで見られます。一番下の行が範囲全体（年度なら年間）の合計です。
  • 個人別：一人ずつの回数です。見出しを押すと並べ替え、色が濃いほど回数が多い人です（担当の偏りの確認に）。
  • 確定版と実績の違い：確定したときから変わったマスの一覧です。
  • 勤務変更：種類ごと・申請した人ごとの件数、承認までの平均時間、条件から外れた申請と理由です。
  • 時間休：人×月の時間数です。年度を選ぶと、上限までの残りも出ます。
  • 「Excelで書き出す」で、選んだ範囲の集計をExcelファイルに保存できます。

システム管理者向け

1期間の進め方（全体の流れ）

希望休が先の場合：

  1. 「期間・流れ・受付の設定」で期間を入れて「期間を保存」し、作成の流れで「希望休が先」を選んで「流れを保存」。
  2. 「申請の受付」に受付期間と調整期間の終わりを入れる（その日付で 受付中 → 調整中 → 締め切り に自動で切り替わります）。
  3. 締め切ったら「申請の一覧・取り込み」で確認し、「申請を勤務表に取り込む」。
  4. 「勤務表の作成」で日直・夜勤・振休・残り当番を作り、「確定してスタッフに配布」。
  5. 配布後の交代・変更・時間休は、スタッフの申請 → 承認で反映されます。
  6. 期間が終わったら「実績の集計・分析」で確認・Excelに保存。

当番が先の場合：日直・夜勤・振休を先に作り、「仮の勤務表」を「スタッフに公開する」にしてから希望休を受け付けます。「申請の受付の分け方」で、「土日祝の×」と「平日の希望休」を2回に分けるか、1回にまとめるかを選べます（あとから変えられます）。

スタッフ・権限の管理
  • 「勤務表の名簿から登録」で、読み込んだ勤務表のチーム編成にいてまだIDがない人を、名前とチームのまま一度に登録できます（「勤務表作成アプリのJSONを読み込む」のあとにも、登録するか聞かれます）。
  • 「＋ スタッフを追加」で1人ずつ、「まとめて追加」で名前の一覧から一度に登録できます。仮のIDと仮パスワードが表示されるので、印刷か書き写しをして本人に渡します（閉じると二度と表示されません）。
  • ログインのIDは職員番号（6桁）です。本人が初回ログイン時に、仮のIDから自分の職員番号に変えます（それまでは状態が「初回ログイン前」「職員番号の登録前」）。職員番号がわかっていれば、追加のときに直接入れてもかまいません。番号の間違いは「編集」でも直せます。
  • 名前は、勤務表の名簿と同じ表記（漢字・空白）にしてください。違うと、その人は申請や集計で正しく扱われません（「期間・流れ・受付の設定」に食い違いの一覧が出ます）。
  • 「編集」で「承認者」「システム管理者」にチェックすると、その権限が付きます。一時的に止めるときは「有効」を外します。
  • 「削除」でスタッフを消せます（元に戻せません）。試験用のIDや辞めた人に使います。申請・勤務変更・勤務表の記録は名前で残ります。自分自身は削除できません。
  • パスワードを忘れた人は「パスワード再発行」で新しい仮パスワードを発行します。
期間・流れ・受付の設定
  • 期間：勤務表を作る期間（6か月以内）。
  • 作成の流れ：希望休が先／当番が先。当番が先では「申請の受付の分け方」と「仮の勤務表」を設定します。
  • 申請の受付：受付期間・調整期間の終わりを入れると日付で自動的に切り替わります。「受付中にする」「調整中にする」「締め切る」「受付前に戻す」で手動にもでき、「日付どおりにする」で自動に戻ります。
  • 時間休の設定：始業・終業・休憩（日によって違えば「別の休憩」も）、1年度の上限（日）、1日分の時間数、年度の始まりの月。下に今年度の使用時間の一覧が出ます。
  • 勤務表データ：勤務表作成アプリのJSONの読み込み・書き出し（バックアップにも使えます）。
申請の一覧・取り込み
  • 全員の希望休を日ごとの表で見られます。マスを押すと、本人の代わりに申請・取り消しができます。
  • 締め切ったら「申請を勤務表に取り込む」で勤務表に入れます。勤務表とぶつかって取り込めなかったものは一覧で表示されます。
勤務表の作成・確定・配布
  • 「勤務表の作成」で勤務表作成アプリが開きます。作り方はアプリ内の「📖 作り方」を見てください。変更は自動で保存されます。
  • 別の画面やほかの人の変更とぶつかったときは【更新の衝突】と出ます。「最新の内容を読み込み直す」を押して、直前の変更をもう一度行ってください。
  • できあがったら「確定してスタッフに配布」。確定した版はすべて保存され、配り直すと「第2版」のように版が上がります。集計には期間ごとに最後に確定した版を使います。今配布している版とまったく同じ内容のときは、確定し直す前に確かめる画面が出ます。
承認・取り消しの代理
  • システム管理者は、自分が関わる申請も承認できます。「管理者の承認」では、受け手の代わりに承認すること（「受け手の代わりに承認」）もできます。
  • 承認済みの申請は、「管理者の承認」の「すべて」から「承認後の取り消しを申請」で、本人に代わって取り消しを申請できます（本人にお知らせが届きます）。
操作記録・困ったとき
  • 「操作記録」で、ログイン・権限の変更・申請・承認などの記録を確認できます。
  • システム管理者のパスワードを忘れたときは、Apps Scriptの画面で関数「管理者パスワード再発行」を選んで実行すると、実行ログに新しい仮パスワードが出ます。
  • アプリを直したときは、Apps Scriptに「コード.gs」と「index.html」を貼り直し、「デプロイを管理」で「新バージョン」としてデプロイします（URLは変わりません）。
  • データは、初期設定を行ったアカウントのGoogleドライブの「勤務管理データ」に入っています。スタッフには共有しないでください。

スタッフを追加

スタッフをまとめて追加

1行に「チーム名: 名前、名前、…」の形で入れます。下の番号から順に仮のIDが付きます。本人が初回ログイン時に、自分の職員番号（6桁）に変えます。すでに同じ名前の人がいる場合は飛ばします。

仮ID・仮パスワード（この画面を閉じると二度と表示されません）

印刷するか書き写して、本人に渡してください。本人は初回ログイン時に自分のパスワードに変更します。

ID名前チーム仮パスワード

ログインのURLはシステム管理者にたずねてください。初回ログイン時に、自分の職員番号（6桁）と、自分だけが知っているパスワードを登録します。2回目からは職員番号でログインします。
